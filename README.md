# Data-analysis-nassau-candy-project

This project is a Business Analytics Dashboard developed using Python, Streamlit, Pandas, and Plotly. The main purpose of the project is to analyze and visualize business sales data in an interactive and user-friendly way. The dashboard helps users understand important business metrics such as total sales, total profit, gross margin, and product performance.

The project uses the Nassau Candy dataset, which contains information related to products, divisions, sales, costs, and profits. Various data analysis techniques and visualizations are used to convert raw business data into meaningful insights.

The dashboard includes several interactive features such as division filtering, date range selection, product search, and margin threshold filtering. Users can dynamically explore the dataset and analyze business performance in real time.

Different charts such as pie charts, bar graphs, scatter plots, box plots, and Pareto analysis are used to represent business trends visually. KPI cards display important metrics like total sales, total profit, and average margin for quick understanding.

The project also focuses on creating a modern and attractive user interface using custom CSS styling and responsive dashboard components. Overall, this dashboard helps businesses make better data-driven decisions by simplifying complex data analysis into interactive visual insights.
